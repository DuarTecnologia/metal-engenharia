# Metal Engenharia

Site institucional estático em português, com HTML, CSS e imagens WebP.

Abra `index.html` em um navegador para visualizar. As páginas `historia.html` e `projetos.html` usam links relativos. Não há instalação nem etapa de build.

A história e os exemplos de depoimentos são fictícios e estão identificados nas páginas de apresentação.
